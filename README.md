# 학급 대시보드

초등학교 학급 운영에 매일 쓰는 도구를 한 화면에 모았어요. 아침에 켜 두면 오늘 시간표와 알림장, 다가오는 행사, 아직 확인할 것이 한눈에 보여요. 과제나 안내장을 받으면 학생 이름을 눌러 빨간 도장을 찍으면 돼요.

바로 쓰기: https://eunhorang.github.io/class-dashboard/

처음 열면 둘러보기용 예시 반이 들어 있어요. 화면 위쪽의 `예시 지우고 우리 반으로 시작하기`를 누르면 빈 대시보드에서 시작해요.

## 들어 있는 기능

| 묶음 | 기능 | 하는 일 |
| --- | --- | --- |
| 매일 | 오늘 | 날짜·지금 교시·급훈·시계, 오늘 시간표, 알림장, 학습 사이트, 다가오는 행사, 아직 확인할 것 |
| | 시간표 | 요일과 교시로 짠 기초시간표. 칸을 누르면 과목을 바꾸고 교시 시간을 맞추면 지금 몇 교시인지 보여요 |
| | 알림장 | 날짜마다 한 줄에 하나씩 적어요. 크게 보기로 TV에 띄우고 복사해서 누리집에 붙여 넣어요 |
| 체크 | 출결 | 학생 이름을 눌러 결석·지각·조퇴·결과와 사유를 적어요. 달별로 모아 엑셀에서 여는 CSV 파일로 저장해요. 그날 결석한 학생은 아침독서와 뽑기에서 빠져요 |
| | 과제 · 안내장 · 미션 | 항목을 만들어요. 낸(성공한) 학생 이름을 눌러 도장을 찍어요. 못 낸 사람이 바로 보여요 |
| | 아침독서 | 날짜마다 읽은 학생에게 도장을 찍고 이달에 몇 번 읽었는지 알려 줘요 |
| | 1인1역 | 역할마다 맡은 학생을 정하고 날마다 했는지 도장을 찍어요. `역할 돌리기`로 한 칸씩 옮겨요 |
| 관리 | 학생 명단 | 엑셀·나이스에서 복사한 명단을 붙여 넣으면 번호 칸과 머리줄은 빼고 이름만 들어가요. 전학 간 학생은 기록을 남긴 채 체크에서 빠져요. `명단 인쇄`를 누르면 A4 한 장짜리 명렬표가 나와요. 확인용 빈칸을 붙이면 종이 체크표로 쓸 수 있어요 |
| | 관찰 기록 | 학생마다 날짜·영역별로 본 것을 쌓아요. 기록이 적은 학생을 알려 줘요. 화면은 열 때마다 가려져 있어요 |
| | 평가 | 수행평가는 매우잘함·잘함·보통(노력필요) 3단계로 누르고 단원평가는 점수를 적어요. `학생별로 보기`에서 모든 평가를 한 표로 모아 보고 엑셀에서 여는 CSV 파일로 저장해요. 관찰 기록처럼 열 때마다 가려져 있어요 |
| | 학급운영비 | 예산, 받은 돈, 쓴 돈, 남은 돈. 엑셀에서 여는 CSV 파일로 저장해요 |
| | 행사 | 학교·학급 행사와 D-day |
| | 학습 사이트 | 자주 여는 사이트 모음. 앞쪽 여섯 개는 오늘 화면에도 단추로 보여요 |
| 놀이 | 게임 | 초성 퀴즈, 업다운 숫자 맞히기, 10초 멈추기, OX 퀴즈. 초성 퀴즈와 OX 퀴즈는 `준비된 묶음`에서 3~4학년 수준의 문제 묶음(초성 6개, OX 5개)을 골라 넣을 수 있어요 |
| | 뽑기 | 돌림판, 순서 정하기, 모둠 나누기([빙글빙글 돌림판](https://eunhorang.github.io/bingle-wheel/)에서 가져왔어요) |
| | 타이머 | 활동 시간 타이머와 스톱워치. 다른 화면으로 가도 시간은 계속 흘러요 |

## 우리 반에 맞추기

- **기능 켜고 끄기**: `설정 → 쓰는 기능`에서 끄면 목차와 오늘 화면에서 사라져요. 다시 켜면 적어 둔 자료가 그대로 나와요. 출결을 끄면 아침독서와 뽑기도 결석을 따지지 않아요.
- **이름과 급훈**: `설정 → 대시보드 이름과 급훈`. 이름은 목차 맨 위에, 급훈은 오늘 화면 가운데에 보여요.
- **새 학년도**: 학년이나 학급이 바뀌면 `설정 → 새 학년도 시작하기`. 지난 자료는 백업 파일로 먼저 저장하고 교시 시간·학습 사이트·게임 문제처럼 그대로 쓸 것은 골라서 남겨요.
- **크게 보기**: 목차 아래 `크게 보기`를 누르면 목차를 접고 화면 가득 보여 줘요. 교실 TV에 띄울 때 써요.

## 저장과 개인정보

- 모든 자료는 쓰는 컴퓨터의 브라우저(localStorage)에만 저장해요. 로그인도 서버도 없고 학생 이름이나 기록을 어디로도 보내지 않아요. 방문 통계도 넣지 않았어요. `index.html`의 보안 규칙(Content-Security-Policy)이 이 주소 밖으로 나가는 요청을 브라우저에서 막고, 이 내용은 `설정` 맨 위 "자료가 저장되는 곳"에 적혀 있어요. 바깥 글꼴이나 스크립트를 새로 쓰려면 이 규칙도 함께 고쳐야 해요.
- 학교 컴퓨터는 다시 켜면 저장한 것이 지워지기도 해요. `설정 → 백업 파일 저장`으로 일주일에 한 번쯤 파일을 받아 두고 다른 컴퓨터에서는 `백업 파일 불러오기`로 되살려요.
- 출결, 관찰 기록, 평가는 학생 개인정보예요. 관찰 기록과 평가는 열 때마다 한 번 더 눌러야 보이고 5분 동안 손대지 않으면 다시 가려져요. 오늘 화면에는 재적·출석·결석 숫자만 나오고 사유는 나오지 않아요. 백업 파일과 저장한 CSV 파일에도 이 기록이 들어 있으니 학교 규정에 맞게 보관해 주세요.
- 같은 주소(eunhorang.github.io)의 빙글빙글 돌림판에 저장해 둔 목록은 `학생 명단 → 돌림판 목록 불러오기`로 가져올 수 있어요.
- 뽑기와 게임의 무작위는 브라우저의 암호용 난수(`crypto.getRandomValues`)로 정해요.
- 한 번 열어 두면 인터넷이 끊겨도 열려요.

## 내 컴퓨터에서 미리 보기

```bash
python3 -m http.server 4395 --directory class-dashboard
```

그다음 브라우저에서 `http://localhost:4395`를 열어요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 왼쪽 목차와 본문 틀, 창, 알림 |
| `css/style.css` | 색, 글자 크기, 괘선과 도장, 화면 크기별 배치 |
| `js/core/` | 저장(`store.js`), 화면 부품과 도장판(`ui.js`), 날짜·난수(`util.js`), 한국어(`korean.js`), 소리(`sound.js`), 돌림판(`wheel.js`) |
| `js/app.js` | 목차, 화면 오가기, 기능 켜고 끄기, 크게 보기 |
| `js/modules/` | 기능 하나에 파일 하나(오늘, 시간표, 알림장, 출결, 체크, 아침독서, 1인1역, 명단, 관찰 기록, 평가, 운영비, 행사, 사이트, 게임, 뽑기, 타이머, 설정) |
| `js/data/quiz-bank.js` | 게임의 준비된 묶음(3~4학년 초성 낱말과 OX 문제). 묶음을 더하거나 문제를 고칠 때 이 파일을 고쳐요 |
| `sw.js` | 인터넷이 끊겨도 열리게 해 주는 서비스 워커 |
| `fonts/pretendard/` | Pretendard 글꼴 (SIL Open Font License 1.1, `LICENSE.txt`) |
| `tools/` | 아이콘과 링크 미리보기 그림(`og.png`)을 다시 찍는 원본과 스크립트 |

## 고쳐서 다시 올릴 때

- `sw.js`의 `CACHE` 끝 숫자와 `index.html`·`sw.js`에 적힌 `?v=` 숫자를 함께 올려요. 그래야 전에 열어 본 컴퓨터도 새 파일을 받아요.
- 아이콘이나 `og.png`를 바꾸면 `tools/make-assets.sh`로 다시 찍고 `index.html`의 `og:image` 주소 끝 `?v=` 숫자도 올려요.
